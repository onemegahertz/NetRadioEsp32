# 🔧 Исправление всех проблем NetRadio v.3

## ✅ Что исправлено в новой версии:

### 1. Добавлена кнопка VOL- на экране
Теперь на экране 4 сенсорные кнопки:
- **PREV** (синяя) - предыдущая станция
- **NEXT** (зелёная) - следующая станция
- **VOL-** (оранжевая) - уменьшить громкость
- **VOL+** (красная) - увеличить громкость

### 2. WiFi настройки вынесены в начало кода
В начале скетча есть отдельный блок:
```cpp
// ==================== WiFi CONFIGURATION ====================
#define WIFI_SSID     ""  // <-- Введите имя вашей WiFi сети
#define WIFI_PASSWORD ""  // <-- Введите пароль вашей WiFi сети
// ============================================================
```

Просто введите ваши данные и загрузите прошивку!

### 3. Убрана кнопка MODE
Вместо переключения режимов кнопкой, теперь используется весь экран для отображения информации. Режим можно менять через веб-интерфейс.

### 4. Исправлен тачскрин
Использованы правильные настройки из Random Nerd Tutorials:
- Отдельная SPI шина VSPI для тачскрина
- Библиотека XPT2046_Touchscreen by Paul Stoffregen
- Правильная калибровка: `map(p.x, 200, 3700, 1, SCREEN_WIDTH)`

### 5. Используется весь дисплей
Нижняя часть экрана теперь занята кнопками управления, нет пустого места.

## 🔧 Инструкция по установке:

### Шаг 1: Установите библиотеку XPT2046_Touchscreen

1. Откройте Arduino IDE
2. Sketch → Include Library → Manage Libraries...
3. Найдите: **XPT2046_Touchscreen** by Paul Stoffregen
4. Нажмите **Install**

### Шаг 2: Замените User_Setup.h

1. Скачайте файл **User_Setup_CYD.h**
2. Найдите папку библиотеки TFT_eSPI:
   ```
   C:\Users\[USER]\Documents\Arduino\libraries\TFT_eSPI\
   ```
3. Замените файл `User_Setup.h` на скачанный `User_Setup_CYD.h`
4. Перезапустите Arduino IDE

### Шаг 3: Настройте WiFi

Откройте файл `NetRadio_v3_CYD.ino` и в начале найдите:
```cpp
// ==================== WiFi CONFIGURATION ====================
#define WIFI_SSID     ""  // <-- Введите имя вашей WiFi сети
#define WIFI_PASSWORD ""  // <-- Введите пароль вашей WiFi сети
// ============================================================
```

Введите ваши данные:
```cpp
#define WIFI_SSID     "MyHomeNetwork"
#define WIFI_PASSWORD "MyPassword123"
```

### Шаг 4: Загрузите прошивку

1. Подключите CYD через USB
2. Выберите плату: ESP32 Dev Module
3. Нажмите Upload
4. Откройте Serial Monitor (115200 baud)

## 🎯 Как использовать:

### Сенсорные кнопки на экране:

Нажмите на кнопки в нижней части экрана:
- **PREV** - переключить на предыдущую станцию
- **NEXT** - переключить на следующую станцию
- **VOL-** - уменьшить громкость
- **VOL+** - увеличить громкость

### Физическая кнопка:

- **BTN_VOL_DOWN** (GPIO 22) - уменьшить громкость (если подключена)

### Веб-интерфейс:

Откройте `http://[IP-адрес-CYD]` в браузере для:
- Управления станциями
- Изменения WiFi настроек
- Просмотра статуса

## 🔍 Если тачскрин не работает:

### Проверка 1: Библиотека XPT2046_Touchscreen

Убедитесь что установлена библиотека **XPT2046_Touchscreen** by Paul Stoffregen.

### Проверка 2: User_Setup.h

Убедитесь что в User_Setup.h указаны правильные пины:
```cpp
#define XPT2046_IRQ  36
#define XPT2046_MOSI 32
#define XPT2046_MISO 39
#define XPT2046_CLK  25
#define XPT2046_CS   33
```

### Проверка 3: Инициализация в коде

В скетче должно быть:
```cpp
SPIClass touchscreenSPI = SPIClass(VSPI);
XPT2046_Touchscreen touchscreen(XPT2046_CS, XPT2046_IRQ);

void setup() {
  touchscreenSPI.begin(XPT2046_CLK, XPT2046_MISO, XPT2046_MOSI, XPT2046_CS);
  touchscreen.begin(touchscreenSPI);
  touchscreen.setRotation(1);
}
```

### Проверка 4: Калибровка

Правильная калибровка из Random Nerd Tutorials:
```cpp
int x = map(p.x, 200, 3700, 1, SCREEN_WIDTH);
int y = map(p.y, 240, 3800, 1, SCREEN_HEIGHT);
```

### Проверка 5: Serial Monitor

Откройте Serial Monitor и нажмите на экран. Должны появиться сообщения:
```
[TOUCH] Prev station
[TOUCH] Next station
[TOUCH] Volume +
[TOUCH] Volume -
```
