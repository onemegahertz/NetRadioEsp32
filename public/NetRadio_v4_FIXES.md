# 🔧 Исправления NetRadio v.4

## ✅ Исправленные ошибки компиляции

### 1. Bluetooth A2DP API

**Проблема:** Новая версия библиотеки ESP32-A2DP изменила API инициализации.

**Было (не работает):**
```cpp
i2s_pin_config_t pin_config = {
  .bck_io_num = I2S_BCLK,
  .ws_io_num = I2S_LRC,
  .data_out_num = I2S_DOUT,
  .data_in_num = I2S_PIN_NO_CHANGE
};

a2dp_sink.set_pin_config(pin_config);
a2dp_sink.start("NetRadio Speaker");
```

**Стало (работает):**
```cpp
a2dp_sink.set_volume(64);  // 0-128
a2dp_sink.start("NetRadio Speaker");
```

**Объяснение:** В новой версии библиотеки ESP32-A2DP конфигурация I2S пинов происходит автоматически через библиотеку ESP32-audioI2S. Не нужно вручную настраивать пины для Bluetooth.

### 2. Конфликт функции `map()`

**Проблема:** Библиотека ESP32-A2DP включает `<map>` из C++ STL, что создаёт конфликт с Arduino функцией `map()`.

**Было (ошибка компиляции):**
```cpp
int x = map(p.x, 200, 3700, 1, SCREEN_WIDTH);
int y = map(p.y, 240, 3800, 1, SCREEN_HEIGHT);
tft.fillRect(10, 130, map(currentVolume, 0, 21, 0, 300), 20, TFT_GREEN);
```

**Стало (работает):**
```cpp
int x = ::map(p.x, 200, 3700, 1, SCREEN_WIDTH);
int y = ::map(p.y, 240, 3800, 1, SCREEN_HEIGHT);
tft.fillRect(10, 130, ::map(currentVolume, 0, 21, 0, 300), 20, TFT_GREEN);
```

**Объяснение:** Добавление `::` перед `map()` явно указывает компилятору использовать Arduino версию функции из глобальной области видимости, а не `std::map` из C++ STL.

## 🔧 Инструкция по установке

### Шаг 1: Установите библиотеки

Откройте Arduino IDE → Sketch → Include Library → Manage Libraries

Установите:
- TFT_eSPI
- XPT2046_Touchscreen
- ESP32-audioI2S (версия 3.0.8!)
- ESP32-A2DP

### Шаг 2: Настройте TFT_eSPI

Замените файл `User_Setup.h` в библиотеке TFT_eSPI на скачанный `User_Setup_CYD.h`.

Путь: `C:\Users\[USER]\Documents\Arduino\libraries\TFT_eSPI\User_Setup.h`

### Шаг 3: Настройте WiFi

Откройте `NetRadio_v4_CYD.ino` и в начале найдите:

```cpp
// ==================== WiFi CONFIGURATION ====================
#define WIFI_SSID     ""  // <-- Введите имя вашей WiFi сети
#define WIFI_PASSWORD ""  // <-- Введите пароль вашей WiFi сети
// ============================================================
```

Введите ваши данные или оставьте пустым для использования WiFi сканера на экране.

### Шаг 4: Загрузите прошивку

1. Подключите CYD через USB
2. Выберите плату: ESP32 Dev Module
3. Partition Scheme: Default 4MB with spiffs
4. Upload Speed: 921600 (или 115200 если проблемы)
5. Нажмите Upload

## 🎯 Как использовать

### WiFi Scanner на экране:

1. Нажмите кнопку **"W"** в правом верхнем углу экрана
2. Дождитесь сканирования сетей (~5 секунд)
3. Выберите сеть из списка (тапните на неё)
4. Нажмите **"CONNECT"**
5. Если сеть защищена - появится экранная клавиатура
6. Введите пароль и нажмите **"OK"**
7. Готово! Радио подключится к WiFi

### Экранная клавиатура:

- **Ряд 1:** QWERTYUIOP (буквы)
- **Ряд 2:** ASDFGHJKL (буквы)
- **Ряд 3:** ZXCVBNM (буквы)
- **Ряд 4:** 0123456789 (цифры)
- **DEL** - удалить последний символ
- **CLEAR** - очистить всё
- **OK** - подключиться

### Bluetooth:

1. Включите Bluetooth на телефоне
2. Найдите устройство **"NetRadio Speaker"**
3. Подключитесь
4. Включите музыку - звук будет через CYD

### Сенсорные кнопки:

- **PREV** - предыдущая станция
- **NEXT** - следующая станция
- **VOL-** - уменьшить громкость
- **VOL+** - увеличить громкость

## 📊 Структура меню

```
Главный экран
```

## 🔍 Решение проблем

### Ошибка компиляции: `i2s_pin_config_t` was not declared

**Решение:** Используйте обновлённый скетч `NetRadio_v4_CYD.ino` с исправленным кодом инициализации Bluetooth.

### Ошибка компиляции: reference to 'map' is ambiguous

**Решение:** Используйте `::map()` вместо `map()` во всех местах скетча.

### Bluetooth не подключается

**Решение:**
- Убедитесь что установлена библиотека ESP32-A2DP
- Проверьте что I2S DAC подключён правильно
- Перезагрузите CYD
- Попробуйте переподключить Bluetooth на телефоне

### WiFi сканер не находит сети

**Решение:**
- Убедитесь что CYD в зоне покрытия WiFi
- Нажмите "REFRESH" для повторного сканирования
- Проверьте что WiFi роутер работает
- Перезагрузите CYD

### Тачскрин не работает

**Решение:**
- Убедитесь что установлена библиотека XPT2046_Touchscreen
- Проверьте User_Setup.h
- Проверьте что пины тачскрина указаны правильно

## 💡 Советы

1. **Используйте стилус** для более точного нажатия на кнопки
2. **Держите CYD близко к роутеру** для лучшего сигнала WiFi
3. **Сохраняйте пароль WiFi** - он автоматически сохраняется в памяти
4. **Используйте веб-интерфейс** для управления станциями
5. **Bluetooth и WiFi могут работать одновременно**

## 📝 Технические детали

### Bluetooth A2DP:
- Профиль: A2DP Sink
- Имя устройства: "NetRadio Speaker"
- Громкость: синхронизируется с радио (0-128)
- Автоматическое переключение между радио и Bluetooth

### WiFi Scanner:
- Максимум сетей: 10
- Сортировка: по RSSI (сильный сигнал первым)
- Время сканирования: ~5 секунд
- Поддержка WPA/WPA2/WEP

### Экранная клавиатура:
- 36 символов (A-Z, 0-9)
- 3 ряда букв + 1 ряд цифр
- Кнопки управления: DEL, CLEAR, OK
