# 🎵 NetRadio v.4 - Полный функционал

## ✨ Новые возможности v.4

### 1. 📡 WiFi Scanner
- Автоматическое сканирование доступных WiFi сетей
- Отображение уровня сигнала (RSSI)
- Индикация защищённых сетей (🔒/🔓)
- Быстрое подключение через веб-интерфейс
- Сохранение настроек WiFi в памяти

### 2. 🔊 Bluetooth Audio (A2DP)
- Подключение Bluetooth колонок и наушников
- Имя устройства: "NetRadio Speaker"
- Автоматическое переключение между интернет-радио и Bluetooth
- Синхронизация громкости

### 3. 🎛️ Улучшенный интерфейс
- 4 сенсорные кнопки на экране
- WiFi настройки в начале кода
- Статус Bluetooth на экране
- Полный экран без пустого места

## 🔧 Настройка

### Шаг 1: WiFi конфигурация

Откройте `NetRadio_v4_CYD.ino` и в начале найдите:

```cpp
// ==================== WiFi CONFIGURATION ====================
#define WIFI_SSID     ""  // <-- Введите имя вашей WiFi сети
#define WIFI_PASSWORD ""  // <-- Введите пароль вашей WiFi сети
// ============================================================
```

Введите ваши данные:
```cpp
#define WIFI_SSID     "MyHomeNetwork"
#define WIFI_PASSWORD "MyPassword123"
```

**Или** используйте веб-интерфейс для сканирования и подключения.

### Шаг 2: User_Setup.h

Замените файл `User_Setup.h` в библиотеке TFT_eSPI на скачанный `User_Setup_CYD.h`.

### Шаг 3: Загрузка прошивки

1. Подключите CYD через USB
2. Выберите плату: ESP32 Dev Module
3. Нажмите Upload
4. Откройте Serial Monitor (115200 baud)

## 📱 Использование

### WiFi Scanner (веб-интерфейс):

1. Откройте `http://[IP-адрес-CYD]` в браузере
2. Найдите раздел "WiFi Networks"
3. Нажмите кнопку **"Scan WiFi"**
4. Выберите сеть из списка
5. Введите пароль
6. Нажмите "Connect"

### Bluetooth подключение:

1. Включите Bluetooth на телефоне/планшете
2. Найдите устройство **"NetRadio Speaker"**
3. Подключитесь
4. Включите музыку на телефоне
5. Звук будет воспроизводиться через CYD

### Сенсорные кнопки:

Нажмите на кнопки в нижней части экрана:
- **PREV** - предыдущая станция
- **NEXT** - следующая станция
- **VOL-** - уменьшить громкость
- **VOL+** - увеличить громкость

## 🔍 Как работает WiFi Scanner

### Алгоритм работы:

1. **Сканирование**: ESP32 ищет все доступные WiFi сети
2. **Сортировка**: Сети сортируются по уровню сигнала (RSSI)
3. **Отображение**: Список показывается в веб-интерфейсе
4. **Выбор**: Пользователь выбирает сеть
5. **Подключение**: Вводится пароль и подключается
6. **Сохранение**: Настройки сохраняются в NVS память

### API Endpoints:

```
GET  /api/wifi/scan          - Сканировать сети
POST /api/wifi/connect       - Подключиться к сети
     {ssid: "name", password: "pass"}
```

## 🔊 Как работает Bluetooth

### Профиль A2DP:

- **A2DP** (Advanced Audio Distribution Profile) - профиль для передачи аудио
- **Sink** - устройство принимает аудио (наша CYD)
- **Source** - устройство передаёт аудио (телефон)

### Алгоритм работы:

1. **Инициализация**: При запуске CYD регистрируется как "NetRadio Speaker"
2. **Обнаружение**: Телефон находит устройство при сканировании Bluetooth
3. **Подключение**: Пользователь подключается к CYD
4. **Воспроизведение**: Аудио с телефона передаётся на I2S DAC
5. **Громкость**: Синхронизируется между радио и Bluetooth

### Код инициализации:

```cpp
BluetoothA2DPSink a2dp_sink;

void initBluetooth() {
  i2s_pin_config_t pin_config = {
    .bck_io_num = I2S_BCLK,
    .ws_io_num = I2S_LRC,
    .data_out_num = I2S_DOUT,
    .data_in_num = I2S_PIN_NO_CHANGE
  };
  
  a2dp_sink.set_pin_config(pin_config);
  a2dp_sink.set_volume(64);  // 0-128
  a2dp_sink.start("NetRadio Speaker");
}
```

## 💡 Советы по использованию

### WiFi:
- Используйте сканер для быстрого подключения
- Сети сортируются по силе сигнала
- Защищённые сети отмечены 🔒
- Настройки сохраняются автоматически

### Bluetooth:
- Подключайте телефон к "NetRadio Speaker"
- Громкость синхронизируется

- Bluetooth работает даже без WiFi

### Комбинированное использование:
- Слушайте интернет-радио через WiFi
- Переключайтесь на Bluetooth для музыки с телефона
- Используйте сенсорные кнопки для управления
- Веб-интерфейс для точной настройки

## 🆘 Решение проблем

### WiFi Scanner не находит сети:
- Убедитесь что WiFi включён
- Проверьте что CYD в зоне покрытия
- Попробуйте переместить CYD ближе к роутеру
- Перезагрузите CYD

### Bluetooth не подключается:
- Убедитесь что Bluetooth включён на телефоне
- Проверьте что устройство "NetRadio Speaker" видно
- Попробуйте отключить и подключить снова
- Перезагрузите CYD

### Нет звука через Bluetooth:
- Проверьте подключение Bluetooth
- Увеличьте громкость на телефоне
- Увеличьте громкость на CYD
- Проверьте подключение I2S DAC

### Тачскрин не работает:
- Убедитесь что установлена библиотека XPT2046_Touchscreen
- Проверьте User_Setup.h
- Попробуйте калибровку через Serial Monitor

## 📝 Технические детали

### WiFi Scanner:
- Максимум сетей: 20
- Сортировка: по RSSI (сильный сигнал первым)
- Время сканирования: ~5 секунд
- API: `/api/wifi/scan`

### Bluetooth A2DP:
- Профиль: A2DP Sink
- Кодек: SBC (по умолчанию)
- Частота: 44.1 kHz
- Битрейт: до 328 kbps
- Имя устройства: "NetRadio Speaker"

### Хранение настроек:
- WiFi: NVS память (Preferences)
- Станции: SD карта (stations.txt)
- Режим дисплея: NVS память
- Громкость: NVS память
