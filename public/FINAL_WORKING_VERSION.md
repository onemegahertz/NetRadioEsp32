## 🔧 Калибровка тачскрина:

Если кнопки не работают, нужно откалибровать координаты!

### Шаг 1: Откройте Serial Monitor

Нажмите на экран и смотрите координаты:
```
[TOUCH] Raw: X=2100 Y=2300 -> Screen: X=178 Y=192
```

### Шаг 2: Проверьте координаты кнопок

Кнопки расположены так:
```
┌────────────────────────────────────┐
│                                    │
│                                    │
│                                    │
│                                    │
│ [PREV]  [NEXT]  [VOL-]  [VOL+]    │ ← y: 200-235
│  0-80   85-160  165-240  245-320  │ ← x координаты
└────────────────────────────────────┘
```

### Шаг 3: Нажмите на каждую кнопку

**PREV (левая нижняя):**
- Должно быть: `X=0-80, Y=200-235`
- Если нет - смотрите какие координаты показывает Serial Monitor

**NEXT:**
- Должно быть: `X=85-160, Y=200-235`

**VOL-:**
- Должно быть: `X=165-240, Y=200-235`

**VOL+:**
- Должно быть: `X=245-320, Y=200-235`

### Шаг 4: Исправьте калибровку

Если координаты неправильные, измените в коде (строка ~450):

**Было:**
```cpp
int screenX = ::map(x, 200, 3800, 0, 320);
int screenY = ::map(y, 200, 3800, 0, 240);
```

**Измените на ваши значения:**
```cpp
int screenX = ::map(x, YOUR_MIN_X, YOUR_MAX_X, 0, 320);
int screenY = ::map(y, YOUR_MIN_Y, YOUR_MAX_Y, 0, 240);
```

**Пример:** Если Serial показывает `Raw: X=300 Y=300` при нажатии в левый верхний угол:
```cpp
int screenX = ::map(x, 300, 3900, 0, 320);
int screenY = ::map(y, 300, 3900, 0, 240);
```

## 🔍 Если кнопки не работают:

### Проверка 1: Serial Monitor

Нажмите на кнопку и смотрите:
```
[TOUCH] Raw: X=2100 Y=2300 -> Screen: X=178 Y=192
[BTN] PREV
```

Если видите `[TOUCH]` но нет `[BTN]` - координаты не попадают в область кнопки.

### Проверка 2: Калибровка

Смотрите какие координаты показывает Serial Monitor при нажатии на кнопки.

**Пример:** Если нажимаете на PREV (должно быть X=0-80, Y=200-235), но видите:
```
[TOUCH] Raw: X=500 Y=3500 -> Screen: X=42 Y=221
```

Значит калибровка правильная! Должно работать.

Если видите:
```
[TOUCH] Raw: X=500 Y=3500 -> Screen: X=42 Y=150
```

Значит Y координата неправильная (150 вместо 221). Нужно изменить калибровку.

### Проверка 3: Область кнопок

В коде (строки ~480-510) проверьте области кнопок:

```cpp
// PREV button (x: 5-80, y: 200-235)
if (screenX >= 5 && screenX <= 80 && screenY >= 200 && screenY <= 235) {
```

Если ваши координаты другие - измените значения.
