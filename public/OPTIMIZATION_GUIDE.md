### 2. Макрос F() для строк (Экономия ~100-200KB RAM)

**Было:**
```cpp
Serial.println("NetRadio v.4.2");
tft.print("Connecting WiFi...");
```

**Стало:**
```cpp
Serial.println(F("NetRadio v.4.2"));
tft.print(F("Connecting WiFi..."));
```

**Как это работает:**
- Без F(): строки хранятся в RAM (ограничена 520KB)
- С F(): строки хранятся в Flash (4MB) и читаются по мере необходимости
- Экономия: ~100-200KB оперативной памяти

### 3. Оптимизированный HTML (Экономия ~10KB)

Убраны лишние пробелы и переносы строк в HTML коде.

## 📋 Инструкция по установке:

### Шаг 1: Обновите User_Setup.h

1. Откройте папку библиотеки TFT_eSPI:
   ```
   C:\Users\[USER]\Documents\Arduino\libraries\TFT_eSPI\
   ```

2. Замените файл `User_Setup.h` на скачанный `User_Setup_CYD.h`

3. Убедитесь что закомментированы:
   ```cpp
   // #define LOAD_FONT6
   // #define LOAD_FONT7
   // #define LOAD_FONT8
   // #define LOAD_GFXFF
   // #define SMOOTH_FONT
   ```

### Шаг 2: Установите библиотеку ESP32-A2DP

1. Откройте Arduino IDE
2. Sketch → Include Library → Manage Libraries...
3. Найдите: **ESP32-A2DP** by pschatzmann
4. Нажмите Install

### Шаг 3: Загрузите скетч

1. Откройте `NetRadio_v4_2_CYD.ino`
2. Убедитесь что в начале файла:
   ```cpp
   #define USE_BLUETOOTH  // ← Раскомментировано!
   ```
3. Выберите плату: ESP32 Dev Module
4. Partition Scheme: Default 4MB with spiffs
5. Нажмите Upload

### Шаг 4: Проверьте размер

После компиляции в Arduino IDE покажется:
```
Скетч использует XXXXXXX байт (XX%) памяти устройства.
```

**Должно быть:** < 1,966,080 байт (100%)

## 🔊 Как использовать Bluetooth:

### Включение/выключение:

На экране появится кнопка **[BT]** в правом нижнем углу.

1. **Нажмите [BT]** - Bluetooth включается
   - На экране: `BT: ON`
   - Устройство "NetRadio" появляется в списке Bluetooth

2. **Подключите телефон:**
   - Включите Bluetooth на телефоне
   - Найдите устройство "NetRadio"
   - Подключитесь
   - На экране: `BT: ON [LINK]` (зелёный)

3. **Включите музыку** - звук пойдёт через CYD

4. **Нажмите [BT] ещё раз** - Bluetooth выключается

### Синхронизация громкости:

Когда Bluetooth подключен:
- Кнопки **VOL+** и **VOL-** регулируют громкость ОДНОВРЕМЕННО:
  - Громкость интернет-радио
  - Громкость Bluetooth аудио

## 🆘 Решение проблем:

### Ошибка: "sketch too big"

**Причина:** Не оптимизирован User_Setup.h

**Решение:**
1. Замените User_Setup.h на оптимизированный
2. Убедитесь что закомментированы LOAD_FONT6/7/8 и LOAD_GFXFF
3. Перезапустите Arduino IDE
4. Скомпилируйте снова

### Ошибка: "BluetoothA2DPSink.h: No such file"

**Причина:** Не установлена библиотека ESP32-A2DP

**Решение:**
1. Library Manager → найдите ESP32-A2DP
2. Установите by pschatzmann
3. Перезапустите Arduino IDE

### Bluetooth не подключается

**Решение:**
1. Убедитесь что `#define USE_BLUETOOTH` раскомментирована
2. Нажмите кнопку [BT] на экране
3. Перезагрузите CYD
4. Попробуйте подключиться с другого устройства

### Нет звука через Bluetooth

**Решение:**
1. Проверьте что подключено устройство (должен быть зелёный [LINK])
2. Увеличьте громкость на телефоне
3. Увеличьте громкость на CYD (кнопка VOL+)
4. Проверьте подключение I2S DAC
