# 🔧 Решение проблемы мерцания LCD 1602

## ❌ Проблема

Нижний ряд дисплея LCD 1602 мерцает при обновлении информации.

## 🔍 Причина

Мерцание вызвано частым использованием функции `lcd.clear()`, которая очищает весь экран и перерисовывает его заново. Это происходит каждую секунду при обновлении времени.

## ✅ Решение

**Обновлённый скетч** использует оптимизированный метод обновления дисплея:

### Что изменилось:

**Старый код (вызывал мерцание):**
```cpp
void updateDisplay() {
  lcd.clear();  // ❌ Очищает весь экран - вызывает мерцание
  
  lcd.setCursor(0, 0);
  lcd.print("Station Name");
  
  lcd.setCursor(0, 1);
  lcd.print("V:12 14:35:22");
}
```

**Новый код (без мерцания):**
```cpp
void updateDisplay() {
  // ✅ Обновляем только изменившиеся символы
  
  // Строка 1: название станции
  lcd.setCursor(0, 0);
  lcd.print("Station Name");
  
  // Строка 2: громкость и время
  lcd.setCursor(0, 1);
  lcd.print("V:12 14:35:22");
  // Без lcd.clear()!
}
```

## 📥 Как исправить

### Шаг 1: Скачайте обновлённый скетч

Нажмите кнопку **"⬇️ Скачать NetRadio_v2_ESP32.ino"** в веб-приложении.

### Шаг 2: Загрузите прошивку

1. Откройте Arduino IDE
2. Откройте скачанный файл `NetRadio_v2_ESP32.ino`
3. Подключите ESP32 через USB
4. Выберите правильный COM порт
5. Нажмите "Upload" (→)
6. Дождитесь завершения загрузки

### Шаг 3: Проверьте результат

После загрузки прошивки мерцание должно исчезнуть!

## 🎯 Что было оптимизировано

1. **Убран `lcd.clear()`** - больше не очищаем весь экран
2. **Частичное обновление** - обновляем только изменившиеся символы
3. **Фиксированная длина** - всегда выводим 16 символов в каждой строке
4. **Позиционирование курсора** - точно указываем где печатать

## 💡 Дополнительные советы

### Если мерцание продолжается:

1. **Проверьте питание LCD**
   - Убедитесь что VCC = 5V (не 3.3V!)
   - Используйте качественный блок питания 5V 2A
   - Добавьте конденсатор 100µF между VCC и GND

2. **Проверьте подключение I2C**
   - SDA → GPIO21
   - SCL → GPIO22
   - Короткие провода (< 20cm)

3. **Попробуйте другой LCD модуль**
   - Некоторые модули имеют брак
   - Попробуйте другой LCD 1602 I2C

4. **Уменьшите частоту обновления**
   - В скетче измените:
   ```cpp
   if (now - lastScreenUpdate > 1000) {  // Было 500ms
     lastScreenUpdate = now;
     updateDisplay();
   }
   ```
   - Увеличьте до 2000ms (2 секунды)
