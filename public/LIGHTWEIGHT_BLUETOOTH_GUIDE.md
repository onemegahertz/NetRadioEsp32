# 🎉 NetRadio v5.3 - ЛЁГКИЙ BLUETOOTH ЧЕРЕЗ ESP-IDF!

## ✨ ГЛАВНАЯ НОВОСТЬ:

**Bluetooth теперь работает БЕЗ библиотеки ESP32-A2DP!**

Используем ESP-IDF напрямую - экономия **~350KB Flash памяти**!

## 📊 Сравнение размеров:

| Версия | Bluetooth | Размер | Помещается? |
|--------|-----------|--------|-------------|
| v5.1 | ESP32-A2DP библиотека | ~2.2MB | ❌ Нет (нужно 3MB) |
| **v5.3** | **ESP-IDF напрямую** | **~1.8MB** | **✅ Да! (в 2MB)** |

**Экономия: ~400KB!**

## 🔧 Как это работает:

### Было (v5.1):
```cpp
#include <BluetoothA2DPSink.h>  // Библиотека ~400KB
BluetoothA2DPSink a2dp;
a2dp.start("NetRadio");
```

### Стало (v5.3):
```cpp
#include "esp_bt.h"              // ESP-IDF напрямую
#include "esp_a2dp_api.h"
// Минимальный код ~150KB
esp_bt_controller_init(&bt_cfg);
esp_a2dp_sink_init();
```

**Разница: ~250KB экономии!**

## 🎯 Что оптимизировано:

### 1. Отключён BLE (не нужен)
```cpp
esp_bt_controller_mem_release(ESP_BT_MODE_BLE);
```
Экономия: ~50KB RAM

### 2. Только Classic Bluetooth
```cpp
bt_cfg.mode = ESP_BT_MODE_CLASSIC_BT;
```
Экономия: ~100KB Flash

### 3. Минимум подключений
```cpp
bt_cfg.bt_max_acl_conn = 1;  // Только 1 устройство
bt_cfg.bt_max_sync_conn = 0; // Без синхронных
```
Экономия: ~50KB RAM

### 4. Без библиотеки-обёртки
Прямой вызов ESP-IDF API вместо ESP32-A2DP
Экономия: ~150KB Flash

**Итого: ~350KB экономии!**

## 🔊 Bluetooth:

### Подключение:

1. Включите Bluetooth на телефоне
2. Найдите устройство **"NetRadio"**
3. Подключитесь
4. На экране появится: `BT: Connected`
5. Включите музыку - звук пойдёт через CYD

### Управление:

- **Вкл/выкл Bluetooth** через веб-интерфейс (кнопка "Toggle BT")
- Автоматическое переподключение при включении телефона

## 🔍 Если Bluetooth не работает:

### Проверка 1: Partition Scheme

Убедитесь что выбрано:
```
Tools → Partition Scheme → Huge APP (3MB No OTA)
```

### Проверка 2: Serial Monitor

При запуске должно быть:
```
[BT] Initializing...
[BT] Ready - device name: NetRadio
```

Если видите:
```
[BT] Init failed!
```
или
```
[BT] Bluedroid init failed!
```

**Решение:** Перезагрузите ESP32 (нажмите кнопку RST)

### Проверка 3: Видимость устройства

1. Включите Bluetooth на телефоне
2. Найдите устройство "NetRadio"
3. Если не видно - проверьте что `btEnabled = true` в коде

### Проверка 4: Подключение

Если устройство видно, но не подключается:
1. Удалите "NetRadio" из списка сохранённых устройств на телефоне
2. Попробуйте подключиться заново
3. Проверьте Serial Monitor - должно быть: `[BT] Connected!`
