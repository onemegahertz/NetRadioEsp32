## 📋 Инструкция по установке:

### Шаг 1: Обновите User_Setup.h

1. Откройте папку библиотеки TFT_eSPI:
   ```
   C:\Users\[USER]\Documents\Arduino\libraries\TFT_eSPI\
   ```

2. Замените файл `User_Setup.h` на скачанный `User_Setup_CYD.h`

3. Убедитесь что закомментированы:
   ```cpp
   // #define LOAD_FONT6
   // #define LOAD_FONT7
   // #define LOAD_FONT8
   // #define LOAD_GFXFF
   // #define SMOOTH_FONT
   ```

### Шаг 2: Загрузите скетч

1. Откройте `NetRadio_v4_3_CYD.ino`
2. Выберите плату: ESP32 Dev Module
3. Partition Scheme: Default 4MB with spiffs
4. Нажмите Upload

### Шаг 3: Проверьте размер

После компиляции в Arduino IDE покажется:
```
Скетч использует XXXXXXX байт (XX%) памяти устройства.
```

**Должно быть:** < 1,966,080 байт (100%) ✅

## 💡 Почему Bluetooth не работает на 2MB Flash:

Библиотека **ESP32-A2DP** сама по себе занимает **~400-600KB Flash памяти**.

Даже с максимальной оптимизацией:
- Базовый код: ~1.2MB
- WiFi + WebServer: ~300KB
- TFT + Touch: ~200KB
- Audio: ~150KB
- **Bluetooth: ~500KB**
- **ИТОГО: ~2.35MB** ❌ (больше 2MB)

Без Bluetooth:
- **ИТОГО: ~1.5MB** ✅ (помещается в 2MB)

## 🆘 Решение проблем:

### Ошибка: "sketch too big"

**Решение:**
1. Используйте версию **v4.3** (без Bluetooth)
2. Убедитесь что User_Setup.h оптимизирован
3. Проверьте что все строки в F() макросе

### Ошибка: "BluetoothA2DPSink.h: No such file"

**Решение:**
- Вы используете v4.3 (без Bluetooth)
- Библиотека ESP32-A2DP не нужна
- Удалите `#include <BluetoothA2DPSink.h>` из кода

### Нет звука

**Решение:**
1. Проверьте подключение I2S DAC
2. Убедитесь что динамик подключён
3. Увеличьте громкость кнопкой VOL+

### Тачскрин не работает

**Решение:**
1. Запустите Diagnostic.ino
2. Проверьте подключение пинов тачскрина
3. Убедитесь что установлена библиотека XPT2046_Touchscreen
