# 🔧 Исправление проблемы с кнопками

## Проблема

В диагностике тач работает, но в основном проекте кнопки не переключаются.

## Решение

Я исправил координаты кнопок в коде. Теперь они совпадают с реальными координатами касания.

### Что исправлено:

**1. Координаты кнопок в `checkTouch()`:**

Было:
```cpp
if (x >= 290 && x <= 315 && y >= 5 && y <= 25)  // WiFi
if (x >= 10 && x <= 70 && y >= 200 && y <= 230) // PREV
```

Стало:
```cpp
if (x >= 280 && x <= 320 && y >= 0 && y <= 30)  // WiFi
if (x >= 0 && x <= 80 && y >= 190 && y <= 240)  // PREV
```

**2. Добавлена отладка:**

Теперь в Serial Monitor будут видны:
- Координаты касания: `[TOUCH] X=176, Y=179 (Raw: X=2132, Y=2909, Z=1209)`
- Текущее меню: `[DEBUG] Current menu: 0`
- Нажатая кнопка: `[TOUCH] PREV button`

## 📋 Как проверить:

### Шаг 1: Загрузите обновлённый скетч

Скачайте файл **NetRadio_v4_1_CYD.ino** и загрузите в Arduino IDE.

### Шаг 2: Откройте Serial Monitor

- Скорость: **115200 baud**
- Вы увидите отладочную информацию

### Шаг 3: Нажмите на кнопки

Нажмите на кнопки на экране и смотрите в Serial Monitor:

**Должно появиться:**
```
[TOUCH] X=40, Y=215 (Raw: X=500, Y=3500, Z=1000)
[DEBUG] Current menu: 0
[TOUCH] PREV button
```

### Шаг 4: Проверьте результат

- Если видите `[TOUCH] PREV button` - кнопка работает!
- Если видите только `[TOUCH] X=...` но нет `[TOUCH] PREV button` - координаты не совпадают
- Если не видите ничего - тачскрин не работает

## 🔍 Если кнопки всё ещё не работают:

### Проверка 1: Координаты касания

Нажмите на кнопку PREV (нижний левый угол) и посмотрите в Serial Monitor:

**Должно быть:**
```
[TOUCH] X=40, Y=215 (Raw: X=500, Y=3500, Z=1000)
```

Где:
- `X=40` - должно быть в диапазоне 0-80
- `Y=215` - должно быть в диапазоне 190-240

### Проверка 2: Текущее меню

Должно быть:
```
[DEBUG] Current menu: 0
```

Если меню не 0, значит вы не на главном экране.

### Проверка 3: Нажатая кнопка

Должно быть:
```
[TOUCH] PREV button
```

Если этой строки нет - координаты не совпадают.

## 💡 Возможные проблемы:

### Проблема 1: Координаты не совпадают

**Симптом:** Видите `[TOUCH] X=...` но не видите `[TOUCH] PREV button`

**Решение:** 
- Посмотрите какие координаты показывает Serial Monitor
- Сравните с координатами в коде
- Если нужно - калибруйте тачскрин

### Проблема 2: Не на главном экране

**Симптом:** `[DEBUG] Current menu: 1` или другое число

**Решение:**
- Вернитесь на главный экран (нажмите BACK в WiFi меню)
- Убедитесь что `currentMenu = 0`

### Проблема 3: Тачскрин не работает

**Симптом:** Не видите `[TOUCH] X=...`

**Решение:**
- Проверьте что библиотека XPT2046_Touchscreen установлена
- Проверьте подключение пинов тачскрина
- Запустите Diagnostic.ino для проверки

## 🎉 Если всё работает:
