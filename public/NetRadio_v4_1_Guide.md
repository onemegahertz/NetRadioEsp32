## ✨ Новая возможность: Опциональный Bluetooth!

Теперь вы можете **выбирать** - использовать Bluetooth или нет!

## 🔧 Как включить Bluetooth

### Шаг 1: Откройте файл скетча

Откройте `NetRadio_v4_1_CYD.ino` в Arduino IDE

### Шаг 2: Найдите строку в начале файла

```cpp
// Раскомментируйте для включения Bluetooth (требует 4MB Flash!)
// #define USE_BLUETOOTH
```

### Шаг 3: Раскомментируйте строку

Уберите `//` в начале строки:

```cpp
// Раскомментируйте для включения Bluetooth (требует 4MB Flash!)
#define USE_BLUETOOTH
```

### Шаг 4: Установите библиотеку ESP32-A2DP

Откройте Arduino IDE → Sketch → Include Library → Manage Libraries

Найдите и установите: **ESP32-A2DP** by pschatzmann

### Шаг 5: Скомпилируйте и загрузите

Нажмите кнопку Upload в Arduino IDE

```

│ [PREV] [NEXT] [VOL-] [VOL+]       │

```

### Элементы Bluetooth на экране:

- **BT: ON/OFF** - статус Bluetooth (включен/выключен)
- **[BT]** - кнопка для включения/выключения Bluetooth
- **[LINK]** - индикатор подключения (зелёный когда подключено устройство)

## 👆 Управление Bluetooth через тачскрин

### Включение/выключение Bluetooth:

Нажмите на кнопку **[BT]** в правом нижнем углу экрана (координаты: x=250-310, y=180-200)

### Что происходит:

1. **Первое нажатие** - Bluetooth выключается
   - На экране: `BT: OFF`
   - Устройство "NetRadio Speaker" исчезает из списка Bluetooth устройств
   
2. **Второе нажатие** - Bluetooth включается
   - На экране: `BT: ON`
   - Устройство "NetRadio Speaker" появляется в списке Bluetooth устройств

### Подключение устройства:

1. Включите Bluetooth на телефоне/планшете
2. Найдите устройство "NetRadio Speaker"
3. Подключитесь
4. На экране появится зелёный индикатор **[LINK]**
5. Включите музыку - звук пойдёт через CYD

## 🔊 Синхронизация громкости

Когда Bluetooth подключен:
- Кнопки **VOL+** и **VOL-** на экране регулируют громкость ОДНОВРЕМЕННО:
  - Громкость интернет-радио
  - Громкость Bluetooth аудио

Это удобно - не нужно регулировать громкость отдельно для каждого источника!

## 📋 Пошаговая инструкция

### Для плат с 2MB Flash (ESP32-2432S028):

1. **НЕ раскомментируйте** строку `#define USE_BLUETOOTH`
2. Установите библиотеки:
   - TFT_eSPI
   - XPT2046_Touchscreen
   - ESP32-audioI2S (v3.0.8!)
3. Замените User_Setup.h
4. Скомпилируйте и загрузите
5. **Результат:** WiFi сканер, тачскрин, SD карта, погода - всё работает!

### Для плат с 4MB Flash (ESP32-WROOM-32 и аналоги):

1. **Раскомментируйте** строку `#define USE_BLUETOOTH`
2. Установите библиотеки:
   - TFT_eSPI
   - XPT2046_Touchscreen
   - ESP32-audioI2S (v3.0.8!)
   - **ESP32-A2DP** by pschatzmann
3. Замените User_Setup.h
4. Скомпилируйте и загрузите
5. **Результат:** Все функции + Bluetooth!

## 🆘 Решение проблем

### Ошибка компиляции: "BluetoothA2DPSink.h: No such file or directory"

**Решение:** Установите библиотеку ESP32-A2DP через Library Manager

### Ошибка компиляции: "sketch too big"

**Решение:** 
- У вас плата с 2MB Flash
- Закомментируйте строку `#define USE_BLUETOOTH`
- Скомпилируйте снова

### Bluetooth не включается

**Решение:**
- Проверьте что строка `#define USE_BLUETOOTH` раскомментирована
- Перекомпилируйте и загрузите скетч
- Проверьте Serial Monitor (должно быть: "Bluetooth: ENABLED")

### Bluetooth устройство не находится

**Решение:**
- Убедитесь что Bluetooth включен на экране (BT: ON)
- Перезагрузите CYD
- Попробуйте найти устройство с другого телефона
- Проверьте что устройство "NetRadio Speaker" доступно для обнаружения

### Нет звука через Bluetooth

**Решение:**
- Проверьте подключение Bluetooth (должен быть зелёный индикатор [LINK])
- Увеличьте громкость на телефоне
- Увеличьте громкость на CYD (кнопка VOL+)
- Проверьте подключение I2S DAC

- Используйте версию **без Bluetooth**

- Не нужен Bluetooth? Закомментируйте `#define USE_BLUETOOTH`

Это гибкое решение - один код для всех случаев!

## 📝 Технические детали

### Условная компиляция:

```cpp
#ifdef USE_BLUETOOTH
  // Этот код компилируется ТОЛЬКО если USE_BLUETOOTH определен
  #include <BluetoothA2DPSink.h>
  BluetoothA2DPSink a2dp_sink;
  
  void initBluetooth() {
    a2dp_sink.start("NetRadio Speaker");
  }
  
  void toggleBluetooth() {
    if (bluetoothEnabled) {
      a2dp_sink.stop();
    } else {
      a2dp_sink.start("NetRadio Speaker");
    }
  }
#endif
```

### Как это работает:

1. Если `#define USE_BLUETOOTH` **раскомментирована**:
   - Компилятор включает весь Bluetooth код
   - Размер скетча: ~2.2-2.4MB
   - Нужна плата с 4MB Flash

2. Если `#define USE_BLUETOOTH` **закомментирована**:
   - Компилятор **полностью игнорирует** Bluetooth код
   - Размер скетча: ~1.6-1.8MB
   - Работает на плате с 2MB Flash
